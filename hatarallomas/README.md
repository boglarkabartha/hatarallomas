# Határállomás

Pénzügyőrös kvízjáték a vámszabályokról, telepíthető webappként (PWA).

## Fájlok

- `index.html` – maga a játék (300 utas, 3 nehézségi szint, időzítő, hang, rekordok)
- `manifest.webmanifest` – név, ikon, színek a telepítéshez
- `sw.js` – offline működés
- `icons/` – app ikonok

## Ingyenes közzététel GitHub Pages-en

1. Hozz létre egy új, nyilvános tárolót a github.com oldalon, például `hatarallomas` néven.
2. Töltsd fel ide az összes fájlt (Add file → Upload files), a mappaszerkezetet megtartva.
3. Settings → Pages → Branch: `main`, mappa: `/ (root)` → Save.
4. Pár perc múlva elérhető: `https://<felhasználónév>.github.io/hatarallomas/`

## Telepítés telefonra

- Android (Chrome): menü → „Alkalmazás telepítése” vagy „Hozzáadás a kezdőképernyőhöz”.
- iPhone (Safari): Megosztás gomb → „Főképernyőhöz adás”.
